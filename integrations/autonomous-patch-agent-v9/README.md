# v9 宿主治理加固候选

这是与v8隔离的宿主版本，不修改已冻结活动、控制器、模型权重、iLQR或已接受默认补丁。尚未迁移真实活动，也没有真实新跨场景通过结论。旧操作文档见相邻autonomous-patch-agent-v8目录。

## 已接入的约束

- `final_verdict.py`提供统一最终结论，包含适配器、逐案例HDScore/PDMS/RC、历史回归和运动门禁；结论绑定候选代码哈希及度量哈希。候选登记只能消费这一结论。修改已合格度量后资格失效。
- 研究候选仍保留在research frontier，但不能因此更新qualified frontier、最好分锚点或父版本资格。状态分别保存best_observed_candidate、best_qualified_candidate和既有accepted default。
- `search_governance.py`按冻结当前任务与累积回归集合建立阶段。反例阶段一律从破冰开始，即使继承补丁已跑满但分数不合格。首个合格候选前只计有效评估，不扣Patience；首个合格候选建立后，三次小于0.01增益或不合格有效尝试耗尽搜索。搜索停止不等于收敛、验证准入或发布。
- 默认每阶段8次有效算法评估、Patience3、2次基础设施重试配额、最多3个验证池。API/代码/CPU失败不冒充有效闭环评估，仍消耗原有轮数/时间/API预算。8次上限高于Patience但始终有效；如果第8次才出现合格候选，仍保留候选并停止，不能声称已收敛或自动增加配额。
- 预算按`当前+累积回归案例数 × 最少评估轮数 + 验证案例数`估算；区分案例数与实际派发批次。未知适配器不假设可免费批量执行；已有original/cutin适配器登记每派发2案例。耗时使用已核验训练基线耗时与保守配置中的较大值。估计不是保证，所有原硬上限继续生效。
- `trajectory_quality.py`把密集参考轨迹转换到共同世界坐标、对齐绝对时间；检查位置、曲率/转向连续性、速度/加速度/jerk和跨帧振荡。低于0.5m/s仅屏蔽不稳定的推算几何量；实际转角、转向速率、速度和加速度硬边界不豁免。
- 急刹豁免必须有宿主核验且绑定当前合同/观测/时钟的低TTC收据，只豁免单向负jerk冲击。正负交替、正向反弹冲击、越物理上限不豁免。缺TTC适配器时不做豁免。速度裁剪到0且此后保持0的离散饱和单独处理，不允许借此加速反弹。
- `host_motion_contract.py`是宿主冻结的合成测试，由真实候选代码执行；真实GPU派发前必须通过加速/弯曲/低速三项前置检查。LLM不能修改该测试或宿主门禁。闭环后同一门禁还用于训练验收、旧任务回归和跨场景私有验收。
- `pool_stratification.py`仅在宿主侧按预声明拓扑/严重度配额与种子建池；缺分层资产则等待，不按候选成绩重抽。保留整池退役、仅失败子集转训练和全部旧场景永久排除的逻辑。未读任何真实私有验证材料。

```bash
bash integrations/autonomous-patch-agent-v9/run.sh selftest
```

仅运行合成状态机/验证数据与原治理回归；不会启动API或GPU。两个继承测试夹具做了协议适配：研究分支选择前先提供最终资格；合成评测报告补齐密集运动参考。没有删除断言或减弱门禁。另有未修改v8发生资格污染断言失败、v9相同断言通过的因果测试。

## 真实启用边界

新版本不自动接管v8。真实初始化必须由宿主提供`counterexample_cross_scene`的新独立池配置、可用场景适配器及预算继承收据，不能将旧公开172/552材料包装成未见验证池。新分层标签也需宿主准入。

`budget_lineage`收据格式为`host_budget_lineage_v1`，包含previous_state/previous_config的哈希资产。原token、API、GPU、轮数、起始时间与验证池使用量均继承；旧活动缺池计数时需宿主明确证明prior_validation_pool_count。总预算变更必须另附explicit_operator_allocation资产，声明approved_cumulative_budgets。本次未签发扩额或真实迁移收据。

原全局12轮及API/GPU/时间预算没有被放大，因此多阶段规划可能得到资源不足。阶段配额是上限，不是资金授权；不能保证现有预算足够完成所有池更替。真实训练、收敛、泛化仍须独立实测，合成测试通过不能发布默认补丁。
