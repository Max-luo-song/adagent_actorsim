# 轻量道路方向修正与白线路缘约束 v3

独立外部处理版本，复用并保持UniAD及原固定iLQR全部参数/代码不变。旧A-v2的GPU驾驶直接作为关闭对照，不覆盖、不重跑。v3只新增开启道路策略的A，不开放B或默认部署。

## 原因与证据

对A-v2的71次真实相机观测重用已有phase46连续白色路缘检测器。直行命令的训练标签允许3s末端横移不足2m，本身不是车道居中约束。原始局部规划持续右偏，且没有道路方向/白线反馈进入采用参考；因此每次在新的自车坐标系中重复右转。

实际检测的道路世界航向在约-0.005..0.148°之间，自车却累计右偏航12.92°；这不支持相机/里程计存在同量级的持续旋转误差，但也不认证全部神经输入校准。原始规划偏置的神经内部/跨域原因仍未完全区分。这里修复外部闭环形成漂移的机制，不修改神经权重、不宣称已治愈模型域适配。

旧A在2.7s首次违反保守白线净距，约3.9s车体角点穿过相机估计的右白线。原生点云DAC=1漏掉该问题。证据、完整71帧回执及5张图像叠加见输出`off_diagnosis/`。这些是事后诊断，绝不作为在线未来信息输入。

## 在线处理

1. 使用当前RGB、声明的相机标定和已知传感器安装高度，复用phase46白色外路缘检测。连续性及路面/路肩颜色变化过滤车辆、虚线和相同路面内的分隔线。适用范围是局部近直线道路，保留地面平面投影近似和至少0.15m不确定度。
2. 从首个合格观测记录车体与实际检测路缘的距离；用后续当前路缘的方向及距离纠正累计航向/横向漂移，不读取记录路线、场景真值或目标脚本，也不把横向轨迹全部置零。
3. 对六个参考横向位置做固定预算的单次投影优化，组合原始规划拟合、道路方向/位置保持、平滑及UniAD当前可行驶区域距离代价。纵向节点保持原始神经输出，不优化车辆控制、不引入障碍MPC或多候选避障搜索。
4. UniAD地图预测在真实初始车体处也可能报非道路，故只作为**软代价**。它不能冒充实际白线或独立HD边界。
5. 观察到的白线是**硬约束**：检查旋转后整个车体、执行采样间运动、当前动作之后的完整最大制动轨迹；保留车辆0.2m裕度、白线不确定度、近距外推裕度及额外0.05m预留。
6. 普通跟踪动作不通过时，只考虑固定的最大制动/转向回中动作，并进行相同安全检查；两者均不可验证时，本轮仿真不再推进。此终止不冒充车辆已刹停。缺少合格边界或超出可观测纵向范围，不把未知当成自由空间。

在线输入只有当前相机/标定、当前冻结UniAD规划/地图和实际自车运动状态。评分用的背景点云、原始路线、参与者真值和预存未来轨迹均不进入该模块。

硬约束针对**当前观测到的估计边界及不确定度**。不可见路缘、误检、道路曲率和非平面投影仍有观测限制，不能据此宣称真实世界绝对不越线；当前证据主要是右路缘。v3不伪造左侧白线。遇到无法验证的状态会拒绝动作/终止仿真。

## 运行

输出已准备，无需prepare第二次：

```bash
D=${HUGSIM_ROOT}/integrations/light-road-boundary-v3
bash "$D/run.sh" check
bash "$D/run.sh" baseline
```

默认输出为`phase26/light_road551_v3`。保持与A-v2相同的场景、原始参与者、源第10帧初始位姿、4m/s初速、随机种子、模型/跟踪器、70步/7s观察及墙钟预算；唯一新处理为声明的道路参考/执行安全策略。GPU入口检查实际CUDA、服务锁、实际GPU进程及STOP，不停止已有任务。

原准入和分流原生评分保留。额外预注册：最大初始车体横向漂移≤0.5m、相对观测路缘航向误差≤3°、所有已执行动作制动轨迹证书通过、所有实际当前车体净距非负，以及开启/关闭首帧相机完全一致、原始规划在1e-4内一致。写入`road_admission.json`，任何一项失败均不采纳，不在运行后放宽参数。

```bash
bash "$D/run.sh" inspect
bash "$D/run.sh" render
```

当前render展示同一个开启A的上下两行，明确不冒充A/B；关闭对照的视频仍在A-v2。原生`raw_uniad`/`adopted_plan`是规划评分，`executed_path`才是实际未来执行评分。后续观测在自车动作分化后有视角混杂，不能只比较总分归因。

## 验证边界

7项CPU测试覆盖参考不修改神经原数组、车体角点越线、完整制动轨迹越线、不可观测区域拒绝、道路代价和4s原生Motion合成反馈测试。合成反馈中原始局部右偏累积约0.833m，加入观测道路反馈后约0.00152m；这不是新场景GPU闭环结果。

当前真实首帧回放已验证：原参考道路方向误差约0.219m，处理后约0.024m，制动轨迹白线保守净距约0.295m；只属于固定输入诊断，不认证后续驾驶。

高权重道路保持可能抑制后续换道/绕行，必须在新的切入配对中检查退化；本版本只用于修复A，B仍关闭。始终保留原版并可回滚，未经实际开启A验证不改默认版本。
