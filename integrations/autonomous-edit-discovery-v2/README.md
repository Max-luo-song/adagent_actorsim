# Fixed global v15 -> new issues -> general patches

The user-selected global default is v15. New edited episodes run v15 only; v17 remains historical and is not a discovery prerequisite. Completed known passing v15 cases are not reclassified using v17's failures. The old discovery package, results and v7 campaigns are immutable history; the current entry is `integrations/autonomous-patch-agent-v8/new_tasks.sh`.

The first admitted backend searches fresh551 edits. Edits may vary merge/braking durations and target-lane offset; these are offline scenario edits, never controller branches. Before GPU, audit unchanged prefix, actor identity, dynamics, other-participant clearance and a recorded complete path against the NEW target trajectory at10ms. That path is feasibility evidence only; the online controller never receives it. Other scenes still require their own map/runtime/scorer admission.

Run v15 in each legal new edit. If a control failure or a performance challenge is observed, independently repeat v15; matching scene/seed/actor/score contracts are mandatory. Infrastructure failures are not control failures. A qualifying repeat automatically writes failure_reason.json/edit_instruction.json/admission.json, then invokes v8 to diagnose and attempt a minimal causal patch. No alternative-version run is required.

An early terminated control baseline remains terminated. Recovery must execute a complete healthy target and original episode, pass old-task regression and the protected old v15 score, and retain existing code/CPU/native/replay gates. Different-duration scores are not reported as a full-horizon numeric gain. First complete recovery establishes the next real comparable baseline and does not count toward the three-small-gains convergence window. v8 requires all registered held-out scenarios before future accepted_patch.json confirmation; missing adapters remain pending. Work champions do not replace the user-selected global pointer automatically.

New code is screened for obvious scene IDs, actor IDs, fixed directions, task names and experiment-file access. This screening does not prove generalization; real causal tests, regressions and held-out evaluation remain required. No score formula, safety threshold or edit is changed to make a candidate pass.

The v1 discovery ledger is inherited: started_epoch and GPU attempts stay intact, and prior API/token/round counters pass into v8. Restart never resets budgets. `resume` continues the existing allocation, without silently adding another4hours/16attempts. If that allocation expires, the service stops honestly.

```
bash integrations/autonomous-patch-agent-v8/new_tasks.sh resume
bash integrations/autonomous-patch-agent-v8/new_tasks.sh brief
```

Code/CPU preparation is distinct from complete GPU/API validation. A scene is not a failure until measured; an accepted default is not a universal proof for every future scene.
