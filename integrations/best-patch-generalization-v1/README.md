# 已测最好补丁的跨场景评估准备

本入口只完成版本冻结、源数据校验和资产准备，不执行控制动作，不产出泛化分数。

- v15-r2：当前完整551目标闭环中最高分分支。
- v17-r2：稳定对照；v13-r2：只读参考。v13比较是增量收益，不是相对原始UniAD的总收益。
- 预注册172、552、621，原始场景分别运行三个版本，控制代码、物理、原生评分不改，每次独立感知历史。
- 本轮仅评估冻结版本，不继续训练、调参或重置自动迭代预算。
- 缺失、提前终止和基础设施失败分别记录，不把缺失结果补0，也不使用旧551得分代表新场景。

## 命令

```bash
D=${HUGSIM_ROOT}/integrations/best-patch-generalization-v1
bash "$D/run.sh" check
bash "$D/run.sh" status
```

GPU节点上补齐完整19类图像语义和点云语义（仅准备资产，**不是闭环验证**）：

```bash
bash "$D/run.sh" assets --device cuda
```

无需GPU的源文件与原始记录准备：`bash "$D/run.sh" prepare`。每个阶段均先校验已有源资产，不覆盖历史闭环；语义导出按同一模型和推理契约恢复进度。点云阶段中断后保留现场，不将部分结果视为完成。

输出目录：`outputs/gpu_test_service/jobs/unified-open-closed-172-20261022-v4/chain_repair/phase26/best_patch_generalization_v1`。

`evaluation_plan.json`固定比较范围和选择证据；`admission_report.json`记录各场景已完成项、未完成项和道路覆盖诊断；`source_coverage.png`是原始道路点与记录自车路径，**不是预测轨迹、闭环轨迹或已确认可行驶边界**。
