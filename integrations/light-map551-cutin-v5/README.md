# 551 静态地图 A / 原生车切入 B

复用已经完成且通过核验的 `phase26/light_map551_v4/A`，不重跑、不改写 A。
本版本是独立实验，不改变 v4 或默认版本。当前只建立并验证 B，不增加外部避障候选补丁。

## 固定项与唯一干预

UniAD 代码和权重、4 m/s 初速、冻结轻量 iLQR、授权静态道路地图、车体制动门禁、车辆运动学、种子、导航命令、碰撞/终止/评分规则与 A 一致。每步从实际执行状态重渲染并重新运行冻结 UniAD；没有重型障碍 MPC、多候选搜索、NavigationAnchor 或旧恢复逻辑，也不把未来自车位姿作为执行指令。

实际场景是 551（`segment-4468278022208380281_455_820_475_820_with_camera_labels`）。唯一改变是原生 `native:RigidNodes:3` 的运动轨迹；对应原始实例 5、标注 ID `o24FGKGBO7aPlRVYkDyU7A`，通过首帧标注位姿、尺寸与模型绑定核对身份。不增加车辆，不改变道路、天气或其他参与者。

自车从源第 10 帧开始，初始目标车在自车左后方约 3.51 m，左侧间距约 4.36 m，车速约 22.1 m/s。本轮 0.5 s（源时间 1.5 s / 第 15 帧）开始切入，方向为源世界 y 减小、从左侧进入自车车道；持续 2.8 s，在本轮 3.3 s 完成。同期连续减速，持续 4.8 s，在本轮 5.3 s 停车，最终车道中心为源 y=0。准确称为**脚本化车辆轨迹干预**，并非反应式交通策略。

位置采用 C2 时间重参数与五次换道混合；保留原重建车辆的高度轨迹。预先限制速度 ≤35 m/s、加速度 ≤8 m/s²、航向角速度 ≤0.8 rad/s。整个有效源窗口按 0.01 s 对其他原生刚体、非刚体、SMPL 参与者检查车体多边形与高度重叠，要求至少 0.2 m 间距。新车道的轮胎接地与视觉质量不在此项离线证书内。

`scenario/scenario.json` 给出配置、身份、运动限制和其他参与者净距；`scenario/trajectory_design.png` **只是离线设计图**，其中自车路径只有已测得的 A，不表示 B 的实测驾驶。

## 历史、同步与因果诊断

不复用不兼容的部分模型快照。B 使用相同种子重新渲染、推理第 0～5 次共同观测，严格核对像素、实际位姿、检测/原始规划、原始运动头输出及控制量；只重放 A 已实际执行的共同历史动作。随后沿用该驻留 UniAD 的全部历史，不在干预处分支重置。

目标根位姿直接修改原生模型共享张量，不创建碰撞替身。渲染器和环境共享目标位姿/四元数/尺寸/可见性；导出经过实际留出帧插值处理的轨迹，供环境碰撞和原生评分使用。启动时核对其余所有参与者的有效状态逐元素不变、唯一目标轨迹与安装程序一致。GPU 回执 `B/actor_sync.json` 和差分报告中的“相同实际自车位姿下相机发生变化”共同证明干预生效，CPU 准备阶段不声称已经获得相机证据。

`comparison_A_B.json` 逐步记录首次相机、检测、运动预测、原始规划、采用参考、控制和执行状态差异。相同仿真时间但自车已分化的图像明确作为后续不同视点比较，不能把全部后续差异单独归因于目标车的直接视觉影响。真值目标关联只作事后诊断，不进入在线参考选择。

188 个控制 / 189 次观测 / 18.8 s，上限仍为源帧 10～198；这是有效源时间窗，不等于完成原始整条路线。驾驶墙钟预算从 worker 就绪开始 1800 s；准备 2400 s、worker 启动 1200 s、单次推理 300 s、原生评分 900 s，与 A 完全一致。

固定保留 A 的碰撞、地图越界、异常停滞（≥3 s 且参考仍持续要求 ≥2 m/s）、停车和恢复规则。合理减速让行可以正确；观察窗结束尚未恢复则记未决，不改判据强求绕行。只有 B 特有异常得到复现并有机制证据时才提出最小补丁。

## 执行

默认输出 `phase26/light_map551_cutin_v5` 已准备。CPU 检查不等于 GPU 闭环结果：

```bash
D=${HUGSIM_ROOT}/integrations/light-map551-cutin-v5
bash "$D/run.sh" check
bash "$D/run.sh" full
```

`full` 在 CUDA、服务锁、GPU 空闲及 STOP 检查通过后，只运行 B，随后执行原生评分、A/B 差分和同步视频生成。不会停止其他任务。已有有效 B 直接复用；失败或不兼容产物保留并拒绝自动覆盖。

```bash
bash "$D/run.sh" inspect
bash "$D/run.sh" render
```

输出包括 `B/run_report.json`、逐步观测/原始规划/采用参考/控制/跟踪误差、`B/target_detection_association_reference_only.json`、`B/native_eval/native_scores.json`、`comparison_A_B.json` 和 `presentation_A_B/synchronized_3CAM.mp4`。视频上方 A 原行为、下方 B 切入，均为实际闭环观测；结束后不补造观测。叠加图使用正确的源偏移第 10 帧，包含两臂实际自车执行和同一目标车。

原生实际执行评分仅使用有真实未来 2.5 s 执行支持的窗口（完整 188 步时 164 个起点）；原始规划与采用参考的评分另列，不解释成实际执行质量。同步视频和实际评分必须在 GPU B 完成后才能获得。

CPU 测试使用真实冻结跟踪器、原生 Motion 和静态地图门禁，显式替换神经推理与渲染，检查源/本轮双时钟、六次共同历史、错误运动头输出拒绝以及其他车辆误改拒绝。它们不伪装成 GPU B 验证结果。
