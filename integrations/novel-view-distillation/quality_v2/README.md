# 新轨迹蒸馏质量优化 v2

独立实验入口，复用 v1 `20261108T023505Z` 的已验证图片、伪 GT 和掩码。各组均从原始场景 checkpoint 开始；不覆盖 v1，不重跑 DiFix，不训练驾驶模型。

## 针对诊断的改动

- PBR 背景只开放实际参与着色的反照率参数 `_features_dc`，排除无效的背景 `_features_rest`。非 PBR 道路保留 DC 与 SH-rest。
- DC 学习率从 1e-4 提到 1e-3。平衡组与结构组训练 12 轮，按新轨迹／原轨迹 1:1 交替回放。
- 结构组损失为 `0.8 masked L1 + 0.2 masked DSSIM + 0.1 masked edge L1`。DSSIM 采用 11×11 高斯窗口，仅在整窗都有效的位置计算；边缘差只计算两个端点都有效的相邻像素。天空、演员等被排除区域不会进入这些局部监督。
- 原始位置、旋转、尺度、透明度、相机、光照和动态对象均冻结。平衡组、结构组的颜色参数相对初值最大改变：DC 0.25、SH-rest 0.1（原始参数空间，非像素值）；学习率探针组与 v1 一样不加该截断，保证对照。所有组均不扩增高斯。
- 记录每组非零梯度步数，每 25 步记录梯度、参数更新及 Adam 的 RMS/epsilon 比例，帮助识别微小梯度被 epsilon 抑制的问题。保持 Adam epsilon=1e-8，先测量，不同时更改该变量。
- 保存时仍用原 v1 的完整 checkpoint 不变量检查，只允许背景与道路颜色字段改变。渲染器复制已通过实际 GPU 评测的相机精度和完整设备迁移修复，启动时核对普通张量属性及嵌套状态的设备。

## 三组对照

| 组 | 轮数／更新次数 | 调度与损失 | 比较用途 |
|---|---|---|---|
| lr_probe | 3／459 | v1 的 1:2 分块回放、L1；DC 学习率提高 10 倍，其余有效优化设置保持 v1 | 评估 DC 学习率影响 |
| balanced | 12／1224 | 1:1 交替、L1 | 评估更多训练与均衡回放的组合效果；这两个因素未独立分离 |
| structure | 12／1224 | 与 balanced 同采样、学习率和轮数，增加 DSSIM／边缘项 | 分离结构损失的效果 |

总计 2907 次单相机参数更新。没有自动保证画质改善；如果这些颜色优化仍不能恢复细节，结论会体现在对照报告中，再决定是否有限开放静态尺度／透明度。当前版本没有开放几何。

## 运行

空闲 GPU 终端执行：

```bash
Q=${HUGSIM_ROOT}/integrations/novel-view-distillation/quality_v2
bash "$Q/run.sh" all
```

默认输出 `phase26/novel_distillation_v2/runs/<UTC时间>/`。三组依次训练、保存、独立重载评测，最后汇总 `comparison.json`。

CPU 检查：`bash "$Q/run.sh" check`。只准备计划：`bash "$Q/run.sh" prepare /abs/new_output`。只运行结构组：`bash "$Q/run.sh" all /abs/new_output structure`。

阶段间继续：`bash "$Q/run.sh" evaluate /abs/existing_output structure` 或 `train`；已有阶段目录拒绝覆盖。轮次内中断暂不支持恢复，需创建新实验或新组。开始新评测前确认失败输出目录，保留诊断后再使用新目录，不自动删除结果。

关键产物：

- `<组>/train/parameters.json`：实际开放参数与各组学习率。
- `<组>/train/steps.jsonl`：损失、梯度和更新监测。
- `<组>/train/receipt.json`：训练样本、权重变化和不变量校验。
- `<组>/evaluation/report.json`、`before_teacher_after.mp4`：留出帧指标与三相机对比。
- `comparison.json`：v1 与三组实验的指标汇总，仅建议进一步审查的候选，不自动替换当前仿真模型。

## 验收边界

筛查同时要求：新视角 L1 相对蒸馏前下降至少 5%；对教师的边缘梯度误差下降至少 2%；DSSIM 改善；原视角真实 GT 平均 PSNR 下降不超过 0.5 dB。任何一项不通过则不推荐；不会因为 0.18% 的 L1 变化就宣称质量达标。

这些门槛是本次实验预先设定的工程筛查条件，不是视觉真实性认证。复用的 v1 留出帧已用于分析和调参，应视为验证集，不声称未见轨迹测试或闭环驾驶已通过。伪 GT 的时序与多相机一致性仍需检查。

## 测试

`test_quality.py` 覆盖 PBR 活跃参数、冻结几何、采样对照、有效窗口／相邻边界、平坦区有限梯度、结构损失、颜色变化上界、Adam 监测、训练—保存—重载—评测—筛查全流程。全流程 CPU 测试仅用替身代替 CUDA 光栅化；不能替代实际 GPU 反传和画质验证。
