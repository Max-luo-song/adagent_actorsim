# 完整外部补丁开关验证 v1

验证对象是冻结的 v11 外部规划、风险记忆和执行保护整体。旧 v10→v11 只属于增量修复证据，不能替代这次实验。此工具不修改 v11、原有平台或旧结果。

## 第一批四条独立闭环

| 场景 | off | on |
|---|---|---|
| 未编辑 551 | 原始参与者轨迹，外部补丁关闭 | 相同原始场景，完整 v11 开启 |
| 551 别车停车 | 相同已登记原生车切入程序，外部补丁关闭 | 相同编辑场景，完整 v11 开启 |

每条从第 0 次观测开始，独立建立 UniAD 全历史，最多执行 188 控制/18.8 秒，不复用任何旧控制。一次 full 顺序运行四条。已完成并通过回执校验的本实验分支可复用；中断的半成品不会隐式续跑或覆盖。

off/on 共用模型权重、三相机、随机种子、初始状态、车辆参数、原生 UniAD 碰撞后处理、时钟对齐的 HUGSIM iLQR、原生 Motion、地图环境终止和评分代码。开关仅决定外部补丁是否介入参考与执行。

**off 是当前统一执行适配层下的原控制链，不是未经任何集成修改的 HUGSIM 默认软件栈。** 原生碰撞后处理在两边始终开启；不能把其差异当作补丁收益。

运行时编译冻结 runtime，只替换一处控制器导入；CPU 测试核对 AST。on 工厂直接返回冻结 v11 原类。off 保留当前 UniAD 原生后处理后的参考和共享 iLQR 动作，不施加外部规划或执行门。共同环境的碰撞/地图终止条件仍生效。模型推理、编辑、渲染、运动学和评价代码保持共用。

## 判定

只用实际闭环执行轨迹 executed_path 的评分做主判定；同观测 raw/adopted 预测分数为辅助，不能代替独立无补丁闭环。

- 每个场景单独检查，不允许平均分掩盖退化。
- 补丁开启后不得出现碰撞、授权地图越界、未恢复的停止或未完成的观察窗口。
- 正常原场景基线必须先健康完成，才可作不退化判定。
- 工程容差：HDScore 与 PDMS 最多下降 0.01，进度至少保留 95%，额外停车不超过 1 秒。进度/停车/HD 容差沿用既有终止协议中的正常场景门槛；这是容差内不退化，不能称作所有行为完全不变。
- 目标编辑场景的 HDScore 至少提高 0.01，同时通过上述安全与非退化检查。
- 崩溃、资源中断、缺失分数、非有限指标、只有预测分数、历史控制重放、成对外生资产不同均不能判通过。

阈值冻结在新实验前；已有 551 v11 目标结果是已知数据，因此不能称作独立留出集。当前原生评分仍受语义覆盖与重建地图局限约束，formal certification 始终为 false。

## 跨场景缺口

列入 original172、original552、original621，现有历史场景入口只作资产发现回执。这三个场景还没有与 v11 兼容、经过核验的独立授权地图和场景匹配的原生语义/评分适配器。当前渲染驱动、地图、评分包及 actor-count 绑定 551。

**不允许把 551 地图、actor 数量或评分背景套到其他场景。** 这些行标记 unavailable。补齐前，无论四条 551 闭环得分多好，汇总器都不会宣布全局验证通过。后续须以独立发布的场景适配层接入，维持同一补丁参数，不针对各测试场景调参；即便最终矩阵通过，也只支持这个冻结测试集内的结论。

## 执行

在 GPU 节点运行：

```bash
D=${HUGSIM_ROOT}/integrations/patch-global-validation-v1
bash "$D/run.sh" full
```

准备与 CPU 校验：

```bash
bash "$D/run.sh" cpu
bash "$D/run.sh" prepare
bash "$D/run.sh" check
bash "$D/run.sh" summarize
```

输出为 phase26/patch_global_validation_v1：matrix.json 冻结协议与代码/输入，cases/ 场景与开关各自独立的运行，evaluation.json 保留缺失/失败行。GPU lock、CUDA、STOP 和已有部分产物保护在每次运行生效。run.sh full 持有共享锁，子进程继承锁，避免四条之间资源被其他任务插入。

CPU 联调使用真实 iLQR/Motion、模拟渲染与神经推理，不是 GPU 验证结果。
