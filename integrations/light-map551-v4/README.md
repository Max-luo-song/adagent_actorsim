# 551静态地图控制与完整有效时间窗 v4

用户已明确允许控制器接管静态道路地图。本版本使用离线固化道路多边形，在线白线检测调用数为0，保持原冻结UniAD及固定轻量iLQR不变。旧A-v2/v3与失败证据均保留，不覆盖默认版本，不启动B。

## 地图范围与来源

实际551对应`segment-4468278022208380281_455_820_475_820_with_camera_labels`。原始TFRecord首帧位姿与处理后551首帧位姿逐元素一致，原始首帧没有map_features。地图不是伪装的官方HD地图，而是用户授权的离线静态传感器地图。

- 右侧边界：原始标定图像中实际白实线的离线观测，转换到首帧自车世界坐标，拟合残差及源点保留。
- 左侧边界：这段车行道左侧是中央隔离带/路缘；使用原始五相机道路掩码的世界坐标时序融合，去掉移动汽车造成的临时空洞，得到保守路面内边界。没有补造左侧白线。
- 路口：在原始多视角确实观察为路面的区域，用保守内走廊连接隔离带中断处；未观测空间不扩成可行驶区域。
- 地图约覆盖源世界前向15～410m，左侧内边界约8.9～11.4m，右线约-1.86m并随前向位置缓变；保留0.3m地图不确定度、0.2m车辆裕度和额外0.05m安全预留。

`map/map_review.png`和`map/projection_*.jpg`是复核图。`projection_review.json`保留逐图白色像素支持率，部分视图受阴影/投影近似影响不足50%，没有删除这些失败诊断。地图基于跨帧几何拟合和离线复核，不要求每张图单独通过Hough。不能把传感器派生地图当独立测绘真值或绝对物理保证。

Waymo字段定义参考：[Frame](https://github.com/waymo-research/waymo-open-dataset/blob/master/src/waymo_open_dataset/dataset.proto)、[地图要素类型](https://github.com/waymo-research/waymo-open-dataset/blob/master/src/waymo_open_dataset/protos/map.proto)。本地原始记录身份核验在`map/raw_scene_identity.json`。

## 控制与硬约束

当前观测→冻结UniAD→静态地图方向/位置与可行驶区域距离代价→原固定iLQR→完整车体/制动轨迹地图门禁→原生Motion→新观测。

地图点在实际自车状态下转换到当前模型坐标，使用同一张授权多边形计算软距离代价与硬车体净距。门禁覆盖旋转后整个车体、采样间运动及当前动作之后的完整最大制动轨迹。普通动作不合格时仅允许同样检查过的制动动作；无法验证则停止推进，保留真实末速，不把终止冒充已经停车。

在线允许静态地图和实际自车运动状态，不允许未来参与者真值或预存未来自车轨迹。地图源图像在离线构建时可以覆盖整段记录，这是明确授权的静态地图信息。实际参与者真值仍只用于环境碰撞/评分，不进入外部轨迹选择。每步继续重新渲染并运行UniAD，整个episode不重置神经历史，不直接设置未来位姿。

## 完整闭环定义

从已验证的源第10帧/1.0s初始状态开始，到最后有效源第198帧/19.8s：**188个控制、189次观测、18.8s仿真时间**。初速继续为4m/s，纵向速度由UniAD参考决定，没有为追求路线完成而强行加速。

这是剩余可用源时间窗的完整运行，不等于保证跑完约387m原始路线。原生路线目标提前到达也可正常结束；碰撞、地图越界、安全门禁拒绝、资源超时均明确判为未完成。源时间窗结束和原生路线完成分别报告；不冻结/重复末帧参与者来伪造额外未来。

实际执行评分仅使用有真实未来2.5s执行支持的起点；188步完整执行时为164个关键帧，评测参与者最大只读到源198帧。原始/采用规划的传感器安装偏移已按固定跟踪器坐标契约补偿；原生评分算法未改，实际执行流独立来自Motion状态，不能用规划分数代替。


CPU集成检查使用真实Motion/固定iLQR/地图门禁与测试神经服务；这不代表GPU闭环已经执行。实际完成状态以GPU运行产物为准。
